# WhatsApp orders → stock, invoices, daily report (Built with AutoClaw Round 3 · SMB)

A tool for a (fictional) home bakery that takes orders in WhatsApp. Built by AutoClaw in one run; tested on 95 hand-labelled chats (55 never seen by AutoClaw); parser fixed by hand where it failed.

- Case study: https://qlufiq-collab.github.io/bounty-submissions/autoclaw-r3-smb-wa-orders/
- Try the tool: https://qlufiq-collab.github.io/bounty-submissions/autoclaw-r3-smb-wa-orders/tool/
- `files/verify.md` — results per version; `files/parser-fixes.diff` — every manual change
- `files/*chats.txt`, `files/*key.json`, `files/test_parser.py` — reusable test kit
- `files/prompt.txt` — the brief given to AutoClaw

Shop and customers are fictional.
